# Графика тренировки Android, 9 октября 2026

В приложение синхронизирован общий веб-бандл с новыми SVG-знаками действий, объёмными кнопками, полосами здоровья, световыми дугами, осколками, щитом, следами уклонения и печатью опасности. Боевые кнопки скрываются после завершения боя и возвращаются на следующем уровне. Нативный WebView и правила боя не изменялись.

## Проверено

- `:app:verifySectTrainingBundle :app:assembleRustoreDebug --no-daemon`: успешно. Бандлы сайта и Android побайтно совпадают по манифесту, 13 файлов; fingerprint `231bdfde09a1b57715dba4e171c9d77b55f1f4a3c6b7a448d470e250b5f84e25`.
- Установлен именно финальный APK. Android 36 arm64, SwiftShader, font scale 1.3, Wi-Fi и мобильная сеть отключены.
- Полный бой настоящими CDP-событиями касания: 28 нажатий, победа без ошибок действий, лучший личный рекорд сохранён; повторные атаки работают. Экран результата оставляет арену и переход дальше, боевые кнопки скрыты. После перехода кнопки видны снова.
- Числовое здоровье не выходит за границы HUD; скриншот настоящего приложения просмотрен.
- Уход в фон замораживает таймер: 1:30 до/после. Возвращение сохраняет паузу. Android Back закрывает уже открытый диалог настроек, оставляя игровую страницу.
- При проверке одна защитная пауза из-за задержки кадра; бой продолжен кнопкой «Продолжить». Детерминированная симуляция не пропускает время при задержках.
