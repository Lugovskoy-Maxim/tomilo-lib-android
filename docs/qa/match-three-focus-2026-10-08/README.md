# Сад созвездий: компактный Android-интерфейс

На игровом экране: глава, цель, оставшиеся ходы и усиления. Лидеры, редактор, правила, сердца и оформление доступны через меню. Поле квадратное; фон затемнён во время игры.

Android читает серверные руны, слои препятствий, направления полётов и подтверждённые волны каскадов. Анимация удаляет только `clearedCells`, сохраняет происхождение падающих фишек, отображает трещины и счётчики слоёв. Иконки перенесены из новых SVG веб-версии с прозрачностью. Старые ответы сервера без кадров обновляют поле без выдуманного взрыва.

Победа автоматически сохраняется после каскадов. При ошибке остаётся кнопка повтора без цикла запросов. Восстановленная победа с нулём ходов также сохраняется автоматически. Гостевые игры сохраняют существующие локальные правила; новые руны и многослойные препятствия управляются сервером.

Проверено: компиляция Play и RuStore, сборка RuStore debug, lintRustoreDebug, 27 тестов движка/сохранения/протокола, эмулятор Android 36 Pixel 7, шрифт 130%, режим без анимаций, свайп, автоматическая победа и повтор после ошибки. Для сценариев использован настоящий экран и репозиторий с изолированными ответами реального серверного движка. Временная тестовая Activity удалена перед сборкой итогового APK. Авторизованное прохождение реального production-профиля и физический телефон этими проверками не подтверждаются.

Команды: `:app:compilePlayDebugKotlin`, `:app:compileRustoreDebugKotlin`, `:app:assembleRustoreDebug`, `:app:lintRustoreDebug`, `:app:testRustoreDebugUnitTest --tests 'ru.tomilo.lib.mobile.core.MatchThree*' --tests 'ru.tomilo.lib.mobile.data.local.MatchThreeSaveModelTest'`.
