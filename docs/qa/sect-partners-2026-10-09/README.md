# Android: напарники и окно подготовки, 9 октября 2026

Общий пакет «Засады духозверей» синхронизирован с веб-исходниками. В offline-тренировке доступны Линь (+30 к полной комбинации), Юэ (до 40 недостающего HP) и Цин (25 защиты). Заряды ограничены одной попыткой; новый бой восстанавливает их. Кнопка техники, зарядов и ожидания находится под основными действиями. Рекорды с напарниками отделены от одиночных. Kotlin и API этой доработкой не изменялись.

Исправлено окно подготовки: Chrome 133 WebView в тестовом Android вычислял `100vh`/`100dvh`/`100svh`/`100lvh` как 0 при `innerHeight=775`. Диалог сжимался до заголовка. Теперь общая игра использует измеренную высоту visualViewport/innerHeight и пересчитывает её при resize. Окно помещается в экран и прокручивается, включая увеличение текста до 130%.

## Проверки

- `:app:verifySectTrainingBundle :app:assembleRustoreDebug --no-daemon`: BUILD SUCCESSFUL. 13 файлов пакета проверены, готовый APK также проверен по ZIP-байтам каждого файла и manifest.
- Android 16 / API 36 arm64, отдельный эмулятор с программным SwiftShader. Wi-Fi и mobile data отключены, font_scale=1.3.
- Настоящий WebView установленного APK: техника щита вызвана касанием через CDP Input, ошибка поглощает 11 урона, HP остаётся 180/180, щит уменьшается до 14. Показано «Печать!». После reload сохраняются профиль, щит и один оставшийся заряд; выбор напарника заблокирован.
- Полный бой выполнен касаниями. Автоматическая победа, отдельный рекорд shield, исходные solo-рекорды не изменены. Следующий уровень возвращает два заряда.
- Фон останавливает таймер; Android Back закрывает подготовку. Высота диалога 743 px при viewport 775 px, прокрутка до последнего абзаца доступна. После установки конечного APK проверены его manifest и сохранённый профиль.
- `errors=[]`; снимки просмотрены. На программном эмуляторе были защитные паузы при кадрах >250 мс. QA продолжал бой кнопкой, время не пропускалось. Это проверка поведения, не подтверждение FPS физического телефона.
