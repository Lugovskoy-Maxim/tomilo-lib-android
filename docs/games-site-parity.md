# Игры Android и сайта: текущий объём работ

Сравнение выполнено с кодом сайта и сервера в `tomilo-lib_ru` 20 октября 2026 года. Этот список отделяет сделанные изменения от того, что ещё нужно проверить или перенести.

## Уже исправлено в Android

- [x] «Три в ряд»: сетевые запросы отправляются только для администратора, как требует сервер. Для остальных доступна локальная тренировка с явным пояснением про прогресс и награды.
- [x] «Путь» культивации и арена: подключены существующие Android Compose-экраны к секционным API; состояние обновляется после тренировки, смены состава и боя. Проверка на реальном аккаунте и устройстве остаётся открытой.
- [x] Колесо: показывается число бесплатных попыток из ответа сервера, а после времени пополнения состояние запрашивается снова. Убрано обещание повышенного шанса на джекпот, которого сервер не подтверждает.
- [x] Колесо, карточки и «три в ряд»: при смене аккаунта экранное состояние создаётся заново, чтобы не показывать данные предыдущего пользователя.

## Следующие доработки существующих игр

- [ ] Колесо: добавить платную попытку по действующему контракту сервера (`useCoins`, 250 монет, дневной лимит) с повтором по тому же `requestId` после обрыва соединения. Критерий: повтор не списывает монеты дважды, исход попытки можно восстановить после перезапуска.
- [ ] Колесо: сверить попытку за рекламу с серверным подтверждением и текущим рекламным SDK. Критерий: награда появляется только после завершённого просмотра и не выдаётся дважды.
- [ ] Карточки: пройти покупку пака, обмен, перековку, продажу и восстановление экрана после сбоя на реальном аккаунте. Критерий: инвентарь, баланс и история совпадают с сайтом после каждой операции.
- [ ] «Три в ряд»: проверить свайп, бустеры, препятствия, возобновление партии и серверное сохранение победы на устройстве под администратором. Критерий: результат каждого хода и награда совпадают с сервером; обычный аккаунт не получает отказ `403` во время локальной тренировки.
- [ ] «Тропа духозверей»: сравнить встроенный пакет с актуальной сборкой сайта и пройти сценарии тренировки, памяти, паузы и возврата из фона. Критерий: пакет открывается без сети, настройки и прогресс сохраняются.
- [ ] Проверить Play и RuStore сборки, затем основные игровые сценарии на физическом устройстве. Без этого изменения кода не считаются визуально и функционально принятыми.
