## Краткое описание (до ~80 символов)

```
Библиотека манги и манхвы: каталог, чтение, закладки и офлайн (Premium).
```

## Полное описание

```
Tomilo — приложение онлайн-библиотеки tomilo-lib.ru.

• Каталог манги, манхвы и маньхуа
• Поиск, закладки, история чтения
• Удобная читалка
• Уведомления о новых главах для тайтлов в закладках
• Чаты и поддержка
• Офлайн-скачивание глав для Premium
• Без Premium можно скачать главу за просмотр рекламы

Один аккаунт с сайтом: email, Яндекс или VK.

Премиум оформляется как на сайте (ручная активация после оплаты).
Контент 18+ скрыт, пока вы сами не включите его (нужно подтвердить 18+).

Сайт: https://tomilo-lib.ru
```

## Что внутри сборки (consumer / rustore)

- Production API `https://tomilo-lib.ru/api/`
- Реклама Яндекс РСЯ (межстраничная между главами ~1/10 мин, rewarded за офлайн)
- Premium без рекламы и безлимит офлайн
- Админка только для staff-ролей аккаунта (обычным пользователям не видна)

## Технические требования RuStore

- minSdk 26, targetSdk 35
- Подписанный release APK
- Разрешения: Internet, Network state, Notifications (опционально)
- Нет root/эмулятор-only логики

## Сборка

```bash
./scripts/build-rustore.sh
```

APK: `dist/rustore/tomilo-rustore-v…apk`
