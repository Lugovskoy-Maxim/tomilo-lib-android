## Что нового в 1.2.12

- Исправлены фоновые уведомления о новых сообщениях, когда приложение закрыто.
- Добавлены уведомления для личных диалогов и обращений поддержки у администраторов.
- Нажатие на уведомление теперь сразу открывает нужный чат.
- Устранена потеря непрочитанных уведомлений при первом фоновом запуске и при временно отключённом разрешении Android.
- Квадратный значок в строке состояния заменён фирменным монохромным символом TOMILO.
- Для пользователей без аватара добавлены аккуратные градиентные заглушки с инициалами.
- При ошибке загрузки декорации приложение пробует обычный аватар, затем показывает заглушку.
- Исправлено отображение количества прочитанных глав в профиле.
- Удалены разрешение `REQUEST_INSTALL_PACKAGES`, встроенная установка APK и связанный `FileProvider` для соответствия требованиям RuStore.
- Проверка обновлений сохранена, но установка выполняется только через официальный GitHub Release или магазин.

- Версия **1.2.12** (`versionCode 27`)
