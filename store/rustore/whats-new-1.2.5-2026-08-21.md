# tomilo-lib 1.2.5 — 21 августа 2026

## Короткий текст для RuStore

• Исправлена загрузка страниц глав после сетевого сбоя
• Страницы глав переведены на быстрый S3 с автоматическим резервом через CDN
• Офлайн-главы скачиваются с повторными попытками и восстановлением загрузки
• Улучшена совместимость с разными форматами ответа API

## Полный патчноут

### Читалка

- Исправлена критическая ошибка повторной загрузки: повтор больше не отключает сетевой доступ Coil.
- Страницы глав сначала загружаются напрямую из быстрого S3, а CDN остаётся независимым резервным источником.
- Повреждённый кеш обходится новым запросом, а ручное повторение действительно загружает страницу заново.
- Добавлены повторные попытки безопасных GET-запросов API при временных ошибках 408, 429 и 5xx.
- Увеличены таймауты для больших и высоких страниц манхвы.
- Добавлены корректные заголовки приложения для API и медиасервера.

### Офлайн

- Каждая страница скачивается до четырёх раз с чередованием CDN и прямого S3.
- Частично загруженные и повреждённые файлы удаляются перед повторной попыткой.
- Уже скачанные корректные страницы повторно не загружаются, поэтому прерванную главу можно продолжить.
- Поддерживаются оба поля страниц сервера: `pages` и legacy `images`.
