# TOMILO LIB 1.2.9 — 23 августа 2026

## Короткий текст для RuStore

• Длинные WebP в вебтунах теперь показываются полностью
• Страницы разбиваются на безопасные вертикальные плитки
• Повышено качество текста и изображений манхвы
• Снижено потребление памяти при чтении длинных глав

## Полный патчноут

- Добавлен плиточный рендеринг вебтунов через региональное декодирование Android.
- Длинные WebP делятся на вертикальные фрагменты до `4096 px` без пропусков, швов и обрезки нижней части.
- API-размеры страниц используются для точной высоты и корректного восстановления позиции чтения.
- Сохраняется ширина исходника до `2048 px`, поэтому текст остаётся чётким и на QHD-экранах.
- Декодируются только плитки рядом с экраном; полный bitmap высотой 10–30K больше не удерживается в памяти.
- Один исходный файл скачивается только один раз, затем используется локальный управляемый кеш.
- Плиточный режим поддерживает онлайн- и скачанные офлайн-главы.
- Добавлены unit-тесты разбиения без потери пикселей и чтения размеров из актуального API.
- Версия **1.2.9**, код сборки **24**.
