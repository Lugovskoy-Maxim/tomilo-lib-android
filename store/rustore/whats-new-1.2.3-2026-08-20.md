# tomilo-lib 1.2.3 — 20 августа 2026

## Короткий текст для RuStore

• Исправлена навигация: из читалки — к тайтлу, из тайтла — на главную
• Добавлен игровой центр для уже активных механик публичной беты
• Появилась фоновая проверка GitHub Releases и уведомления о новых версиях
• Улучшены надёжность обновления, загрузка игрового профиля и UX переходов

## Полный патчноут

### Навигация чтения

- Кнопка в верхней панели читалки и системный жест «Назад» теперь открывают страницу текущего тайтла.
- При открытии главы по прямой ссылке приложение получает родительский тайтл из данных главы, поэтому переход больше не зависит от истории навигации.
- Переход из читалки перестраивает стек в предсказуемую цепочку **Главная → Тайтл**.
- Кнопка на странице тайтла стала явным переходом на главную, а не возвратом на случайный предыдущий экран.
- Перед выходом из читалки сохраняется текущая позиция чтения.
- Локальная история чтения теперь использует фактический ID тайтла, полученный вместе с главой.

### Игры

- Добавлен новый нативный экран «Игры» с единым обзором игрового профиля.
- На экран вынесены только разделы, уже включённые в публичной бете сайта: поручения, хранилище, секта, карты духа, алхимия и колесо судьбы.
- Ещё не запущенные механики намеренно не отображаются как доступные.
- Поручения и колесо судьбы открываются в нативных экранах приложения.
- Сложные игровые разделы открываются сразу на нужной вкладке официального сайта.
- Добавлены сводка монет, силы секты, уровня секты и количества предметов, превью инвентаря, учеников и карт.
- Данные игровых разделов загружаются параллельно: временный сбой одного API больше не ломает весь экран.
- Добавлены обновление жестом вниз, повтор загрузки и понятное состояние частично недоступных данных.
- Переход в игры добавлен на главную, в профиль и в центр tomilo-lib.

### Обновления приложения

- Добавлена автоматическая проверка официальных GitHub Releases при запуске, восстановлении сети и каждые 12 часов в фоне.
- Когда появляется более новая версия, Android показывает отдельное системное уведомление со ссылкой на официальный релиз.
- Повторное уведомление об одной и той же версии не отправляется.
- Проверка работает без авторизации в tomilo-lib.
- Добавлен резервный способ чтения latest-релиза через официальный redirect, Atom-ленту и список файлов GitHub, если REST API временно ограничил анонимные запросы.
- Перед установкой скачанный APK проверяется: файл должен быть корректным Android-пакетом с package `ru.tomilo.lib.mobile`.

### Интерфейс и исправления

- Название приложения и карточка бренда приведены к единому имени **tomilo-lib**.
- Уточнены подписи кнопок навигации и описания для TalkBack.
- Игровая бета явно отделена от ещё не активированных механик сайта.
- Исправлена запись истории при открытии главы без переданного `titleId`.
