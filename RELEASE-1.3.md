# Tomilo 1.3 (36)

Улучшения офлайн-чтения и загрузок:

- Поиск по сохранённым тайтлам.
- Открытие библиотеки больше не запускает удаление повреждённых и незавершённых загрузок.
- Ручная проверка файлов и очистка недоступны во время скачивания.
- Проверка изображений выполняется вне главного потока.
- Каталог обновляется раз в шесть часов вместо двух запросов на каждую главу.
- Неполный ответ каталога не заменяет сохранённый список глав.
- Остановка загрузки распространяется на копирование файлов и повторные попытки; рекламный кредит возвращается при отмене.
- Повторная загрузка доступна для остановленных глав, статусы различают успех, остановку и ошибки.
- Повторное нажатие скачивания не заменяет работающий пакет; дубликаты глав исключаются.
- Отменённая задача не останавливает новую очередь загрузки.
- Гостевая полка объясняет необходимость входа вместо сообщения об ошибке загрузки.
- Нижняя навигация сообщает экранному диктору выбранную вкладку.

Сеть и производительность:

- Единый клиент изображений и загрузок использует один дисковый кэш и пул соединений.
- Общий таймаут API 45 секунд, повторные попытки прекращаются после отмены.
- Авторизация добавляется до выбора офлайн-кэша.
- После восстановления сети обновляются отметки прочитанных глав.

Версия для пользователей — 1.3. Это обновление существующего приложения с прежним applicationId.
Очередь загрузки пока не восстанавливается после завершения процесса Android; сохранённые страницы можно использовать при повторном скачивании.
