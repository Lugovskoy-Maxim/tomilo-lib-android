# MangaLink

Отдельное Android-приложение и сервер каталога на основе TOMILO LIB. Рабочее название — MangaLink.

## Что работает

- Каталог, поиск по названию и альтернативным названиям, пагинация.
- Один тайтл с несколькими источниками; выбор источника сохраняется на устройстве.
- Встроенная вертикальная читалка, переход между главами, сохранение страницы, повторная загрузка изображения.
- Локальное избранное и отметки открытых глав.
- Серверные парсеры MangaLib и MangaBuff, ручной импорт и почасовое обновление.
- Отдельная SQLite-база: тайтлы, привязки источников, названия/номера глав и ссылки.

Изображения и списки URL страниц **не сохраняются на сервере**. При открытии главы сервер получает метаданные страниц, возвращает ссылки с `Cache-Control: no-store`, а Android загружает изображения прямо из источника. Обложки также хранятся в БД как ссылки. Клиентский загрузчик изображений может использовать обычный локальный кэш.

## Локальный запуск сервера

Нужен Node.js >= 22.13. SQLite входит в Node.js; на Node 22 возможен штатный ExperimentalWarning.

```bash
cd mangalink/server
npm ci
npm run build
export ADMIN_TOKEN="$(openssl rand -hex 32)"
npm start
```

API по умолчанию: `http://127.0.0.1:3100`. База создаётся в `server/data/catalog.sqlite`.

Переменные: `PORT`, `HOST`, `DATABASE_PATH`, `ADMIN_TOKEN` (не менее 24 символов), `SYNC_INTERVAL_MINUTES` (по умолчанию 60).

Для подключения Android-эмулятора при локальном запуске задайте `HOST=0.0.0.0` перед `npm start`. В настройках приложения укажите `http://10.0.2.2:3100`. HTTP разрешён только debug-сборкой. Для release используйте HTTPS через reverse proxy.

## Импорт и привязка источников

В другом терминале задайте тот же `ADMIN_TOKEN`, который использует сервер:

```bash
curl --fail-with-body http://127.0.0.1:3100/api/admin/import \
  -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"url":"https://mangalib.org/ru/manga/SLUG_ТАЙТЛА"}'
```

Возьмите `id` из ответа. Чтобы добавить MangaBuff к **этому же** тайтлу:

```bash
curl --fail-with-body http://127.0.0.1:3100/api/admin/import \
  -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"url":"https://mangabuff.ru/manga/SLUG_ТАЙТЛА","titleId":"ID_ИЗ_ПЕРВОГО_ОТВЕТА"}'
```

Подставьте настоящие ссылки и ID. Без `titleId` новый источник создаёт отдельный тайтл: совпадение названий не считается достаточным основанием для объединения. Повторный импорт того же URL обновляет существующую привязку. Для одного тайтла поддерживается одна привязка к каждому источнику. Зеркала MangaLib и параметры URL нормализуются.

Ручное обновление всех привязок:

```bash
curl --fail-with-body -X POST http://127.0.0.1:3100/api/admin/sync \
  -H "Authorization: Bearer $ADMIN_TOKEN"
```

Ответ `202` означает запуск фонового обновления. При ошибке или пустом списке глав последний успешный снимок сохраняется; `lastError` доступен в карточке источника. Обновление заменяет список глав успешным результатом парсера, сохраняя ID глав с прежними URL. Метаданные карточки берутся из первого импорта.

## Android

Из корня репозитория:

```bash
./gradlew :mangalink:assembleDebug :mangalink:lintDebug
```

APK: `mangalink/android/build/outputs/apk/debug/mangalink-debug.apk`.

Установите APK, откройте настройки MangaLink и укажите адрес своего сервера. Токен администратора в приложение не передаётся. Идентификатор приложения: `ru.tomilo.mangalink` (`.debug` у debug-сборки).

## Docker

Из `mangalink/`:

```bash
cp .env.example .env
# Замените ADMIN_TOKEN в .env на случайный секрет.
docker compose up --build -d
```

SQLite сохраняется в томе `catalog-data`. Порт опубликован только на localhost; внешний HTTPS настраивается reverse proxy. Развёртывание в production не выполнялось.

## API

| Метод | Маршрут | Назначение |
|---|---|---|
| GET | `/health` | Проверка запуска |
| GET | `/api/sources` | Источники |
| GET | `/api/titles?q=&limit=30&offset=0` | Каталог, limit 1–100 |
| GET | `/api/titles/:id` | Тайтл со всеми источниками и главами |
| GET | `/api/chapters/:id/pages` | Временные ссылки на страницы и заголовки для загрузки |
| POST | `/api/admin/import` | Импорт `{url, titleId?}`, Bearer-токен |
| POST | `/api/admin/sync` | Фоновое обновление, Bearer-токен |

## Проверки и границы версии

```bash
cd mangalink/server
npm test
```

Тесты проверяют SQLite, связывание источников, повторный импорт, сохранение данных при ошибках, нормализацию URL, HTTP API и работу парсеров на фикстурах. Они не подтверждают текущую доступность внешних сайтов. Если источник изменил разметку, требует авторизацию или блокирует прямую загрузку, читалка покажет ошибку. Автоматического обхода таких ограничений нет.

Перенесены парсеры из `tomilo-lib-server/server/src/manga-parser/parsers/` и логика извлечения страниц MangaBuff из `manga-parser-chapter-pages.service.ts`. Android использует тот же стек Kotlin / Compose / OkHttp / Coil, что и основное приложение. Остальные источники исходного сервера пока не подключены.

Это первая самостоятельная версия: без аккаунтов, синхронизации избранного между устройствами, офлайн-загрузки глав и административного интерфейса. Автоматическое обновление обновляет уже импортированные тайтлы; весь каталог источников автоматически не обходится.
